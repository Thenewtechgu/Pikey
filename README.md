# Pikey

My verson of a usb rubber ducky that can also be used as a storage device
## The Schematic and board

<img width="1123" height="794" alt="image" src="https://github.com/user-attachments/assets/be1256ac-2800-4ac7-9691-d94ebbc57c02" />

This is the schematic of the board.

Pikey uses
- RP2350B as the controller and communicater between the chip and the computer
- Flash memory (8mb)
- Micro sd card ( can be used for storage of payload or to be used as a normal flash drive)
- A user configurable Tactile Switch
- A 3 color LED (Red, Blue, Green)
